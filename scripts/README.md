# Công cụ bảo trì

Chạy từ thư mục repo (`C:\Users\mrtua\dev\comfycare-vn-website`). Các script đọc dữ liệu ở workspace OneDrive qua `scripts/workspace_paths.py`; đặt biến `COMFYCARE_WORKSPACE` nếu workspace nằm chỗ khác.

- Kiểm tra asset/link: `python scripts/validate_site.py`.
- Kiểm tra kho nội dung theo brain.db: `python scripts/validate_data.py`. Đọc `brain/brain.db` và `brain/content/` trong workspace; so file với baseline lịch sử `projects/website-comfycare/qa-baselines/data-brain-20261012` (không xóa). Hash brain.db so với `qa-baselines/brain-baseline-20261025b.json` (51 bản ghi, mới nhất business 41). Khi brain.db được duyệt thay đổi, tạo baseline mới bên cạnh và trỏ DB_BASELINE sang, không ghi đè bản cũ.
- Đối chiếu giá/nguồn giữa database, `brain/knowledge`, `brain/content` và HTML: `python scripts/validate_sources.py`.
- Regression nội dung local: `node scripts/test-content-sync.cjs` (Playwright; CHATBOT_TEST_URL mặc định http://127.0.0.1:4183; kết quả mặc định ở outputs/content-latest).
- Tạo ảnh responsive: `python scripts/generate_responsive_images.py` (cần Pillow). Chỉ chạy khi thay ảnh nguồn.
- Sản phẩm: `python scripts/build-products.py` sinh `data/products.json` (20 mã, giá bán lẻ, size, màu, quà CS100, link Shopee) từ `brain/knowledge/products/catalog_pricing.md`, `size_guides.md`, `brain/content/products/` và file mô tả sàn `Database Comfycare/Ảnh sản phẩm/<mã>/<MÃ>_Tieu_de_Mo_ta.txt` (các thẻ nội dung trang chi tiết), rồi sinh trang `/san-pham/<mã>/` cho các mã trong `PAGE_SKUS` và thêm vào `sitemap.xml`. CSS/JS riêng: `product-detail.css`, `product-detail.js` (gallery). Ảnh gallery: `node scripts/import-product-images.cjs CS22` chuyển `Database Comfycare/Ảnh sản phẩm/<mã>/N.png` sang `assets/products/<MÃ>/gallery/N.webp`, `N-640.webp`, `N-160.webp` (Chrome qua Playwright, biến PLAYWRIGHT_MODULE, PRODUCT_IMAGE_SOURCE); rồi chạy lại build-products. Ảnh sàn trái brain không đưa lên web: khai báo trong `GALLERY_SKIP` của build-products.py (hiện trống) và xóa file webp tương ứng; ảnh bảng size dùng ở khối chọn size khai báo trong `SIZE_FIGURE`. Chạy lại sau khi sửa brain hoặc CSS; `validate_sources.py` đối chiếu giá/link Shopee của products.json và trang chi tiết.
- Bán hàng trên web (`shop.js`, `shop.css`; trang /cart/, /thanh-toan/, /don-hang/): tắt mặc định (`SHOP.enabled = false` đầu `shop.js`). Sau khi sửa `shop.js`/`shop.css`: `python scripts/build-shop.py` (gắn version lên mọi trang), rồi `python scripts/build-products.py`. Xem thử trên máy: chạy API thử `node scripts/dev-server.mjs` trong repo `comfycare-api`, mở `http://127.0.0.1:4183/?shop-preview=http://127.0.0.1:8787` (chỉ có tác dụng trên localhost). Kiểm thử: `node scripts/test-shop.cjs` (cần API thử đang chạy; SHOP_TEST_URL, SHOP_TEST_API, SHOP_TEST_OUTPUT).
- Chatbot: `python scripts/build-chatbot.py`; nguồn `brain/content/sales_script.md` trong workspace; sau đó `node scripts/test-chatbot.cjs` với Playwright có sẵn.
- Kiểm thử chatbot hỗ trợ CHATBOT_TEST_URL, CHATBOT_TEST_OUTPUT, PLAYWRIGHT_MODULE, CHROME_PATH; mặc định ghi outputs/chatbot-latest.

`outputs/` là kết quả tạm của các lần kiểm tra, không commit, có thể xóa sau mỗi lần publish. Hồ sơ trình duyệt QA dùng thư mục tạm bên ngoài repo. Các công cụ trên không commit/push/deploy.
